# Papin Ads

Все изменения фиксировать в Git после подходящих проверок. В завершении сообщать идентификатор коммита.

Не коммитить `.env`, `access.txt`, базу или токены. Проверки создания/редактирования рекламы выполнять с поддельным API; работающий кабинет использовать для чтения. Реальный запуск рекламы должен быть явно инициирован пользователем.
